# UI 组件清单

> 本清单以 `src/ui/*.svelte` 的实际入口和 `design/prototype-v2.html`、`design/prototype-v2-additions.html` 的实现镜像为准。它描述当前代码已经提供的组件、参数和状态；原型中的按钮用于展示布局与状态，不能代替思源宿主中的真实点击验收。
>
> 状态约定：**空闲**表示可操作；**加载中**表示已显示进行中反馈并锁定重复触发；**成功**表示操作完成后的回执或结果；**失败**表示可读错误，且有重试或恢复入口；**空结果**表示有解释和下一步引导。组件没有独立异步请求时记为“—”，状态由父组件或宿主承载。

## 设置与通用状态约定

`SettingsView.svelte` 是设置入口，参数为 `facade`、可选 `onClose` 和关闭守卫注册器。它把工作区、每日拾遗、阅读、AI、AI 通道、集成、数据与恢复、维护分成八类；设置以显式保存为准，保存期间锁定关闭和重复提交；存在未保存草稿时，窗口关闭、Esc 和“取消修改”都会要求用户选择继续编辑或丢弃。笔记本/打卡项目/AI 日志读取失败均显示重试；维护分类组合了 `BackupPanel`、`FlashcardRecoveryPanel`、`SnapshotGovernance` 和 `AiTagMergePanel`。

所有涉及数据的子组件都应遵守以下交互协议：

1. 加载时显示具体动作文案或进度，并设置 `disabled`/`aria-busy`，避免双击并发。
2. 失败时保留用户输入或已选项，说明是读取、校验、权限还是网络问题，并提供重试；不能用空白代替错误。
3. 空结果必须区分“真实没有数据”和“当前筛选无匹配”，同时提供清除筛选、打开引导或收录入口。
4. 写入状态统一经过服务层；破坏性删除、清空、覆盖和放弃任务必须有确认。失败回滚和可重试语义以对应服务契约为准。
5. 移动端使用 `getFrontend()` 分支和可见按钮；桌面 hover 不是唯一入口。真实思源桌面、Android、触控、读屏和多窗口仍需按 [`docs/BLOCKERS.md`](BLOCKERS.md) 的 B-0002/B-0004/B-0005 等项目验收。

## 原型对照与边界

- `design/prototype-v2.html` 的 Dock 主导航只列今日拾遗、读库、统计和高亮；设置以独立模态层演示，阅读器通过文章卡片的打开动作进入独立阅读演示。阅读演示默认受关闭的桌面实验开关保护；移动画布打开文章只展示思源原生页签回退说明。读库预览与原文跳转使用不同反馈。移动端主导航为今日、读库和高亮，统计/设置位于“更多”；移动设备真实阅读走思源原生页签。
- `design/prototype-v2-additions.html` 补充批量任务、维护、阅读增强、统计回顾和入口归属说明。
- 原型与生产入口的页面承载方式保持一致，但仍用合成数据且不调用宿主 API；真实请求、属性写入、权限和宿主编辑器只在 `src/ui` 与 `src/services` 中生效。其合成状态用于视觉/交互讨论，不等于运行时数据或真实宿主验收。
- 主导航“高亮”已有 `HighlightView` 的当前文档/全库读库摘录入口；`QuotesView` 是另一份不依赖读库收录的未接线组件，不能把它无入口解释为整个全库摘录功能不可用。其独立范围及接线与否需要产品决策。思源 SQL 类型 `b` 表示引述块、`p` 表示段落，不能据 `type='b'` 推断它把普通段落当作摘录。

新增组件或变体时，先更新本文件和 [`docs/UI-STANDARD.md`](UI-STANDARD.md)，再同步原型。若新增数据字段、端点或恢复内容，先更新 [`docs/DATA-CONTRACT.md`](DATA-CONTRACT.md) 和 [`docs/DECISIONS.md`](DECISIONS.md)。完成 UI 改动后至少运行 `pnpm check && pnpm test`，真实宿主行为仍需记录到 `docs/BLOCKERS.md`。
