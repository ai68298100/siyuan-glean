# 小驴拾遗当前状态与精品化路线（2026-10-06）

## 结论先行

小驴拾遗已经从“能把剪藏放进面板”进入“有完整领域模型、数据主权约束和可恢复服务”的阶段。核心产品定位已经清楚：**管理思源里已经存在的文章，帮助用户确认、分拣、阅读、回顾，减少剪藏后吃灰**。代码能力和隔离内核证据很强，但产品还不能称为完成或正式发布，原因是作者真实宿主、Android/移动端、真实模型和外部集成的验收积压，且视觉素材与 GitHub 对外呈现尚未闭环。

当前版本仍为 `1.1.0`。本轮复核结果：

- `pnpm check`：通过，Svelte/TypeScript 0 错误、0 警告。
- `pnpm build`：通过，生产 `dist` 与 `package.zip` 可生成。
- `pnpm test`：1138/1138 通过。修复前唯一失败位于 `tests/import-service.test.mjs:474`，根因是测试写入早于运行时创建时间的固定日期，不是生产逻辑失败。
- `node --test tests/import-service.test.mjs`：22/22 通过。
- 视觉矩阵仍有 24 个 `pending-host` 截图槽位；性能门禁是当前机器合成基线，不等于真实宿主体验。
- 不打 tag、不发 GitHub Release、不上传集市包，直到真实验收和作者授权完成。

- 按来源证据发现候选，普通笔记不会因为位于选定笔记本就被自动收录。
- 首启扫描、候选预览、逐篇确认、补 URL、作为本地文档、排除误报和批量迁移均有代码入口。
- 五态读库：`inbox`、`later`、`reading`、`done`、`archived`；“开始阅读”和“标记读完”语义分离。
- Dock、工作台、看板共用筛选、排序、状态动作和 `clip-store` 写入路径。
- 全文、仅链接、本地文档和未知载体有统一徽章与打开策略。
- 索引可重建，插件数据被清空后文章属性仍是事实源。

### 阅读、摘录与回顾

- 工作台就地预览、正文诊断、来源打开、重新剪藏、阅读页签（实验开关）、最近阅读历史和真实前台阅读分钟。

- 周/月/年回顾、完成热力图、可信完成时间、Markdown/CSV 报告。
- 制卡、分步检查点和跨重载恢复；失败时按确切卡片 ID 处理，不认领其他卡片。

### AI 与生态能力

- 手动/自动富化、摘要、AI 标签、语义查重、相关旧文、阅读伴读、预置动作、本文问答和作者建议。
- 共享额度、串行队列、失败降级、关闭开关、通道/动作/用量来源标识和数据主权守门。
- Pocket、Omnivore、wallabag 导入；思源收集箱；单文件 HTML 快照；小驴打卡桥；对外只读/可选写入桥。
- AI 排版计划、独立整理稿、乱码诊断、链接显示优化和图片隐私边界。

### 工程与质量基础

- domain/API/UI 分层、内核端点集中、属性写入集中和架构测试守门。
- 导入、快照、AI 批量、制卡、外部删除、索引重建等路径具备失败、暂停、恢复或重试语义。

- 移动端底栏、顶部栏、筛选抽屉、触控命中区、键盘避让、安全区、横屏、大字和离线重试均已有代码层处理。

当前最大的管理问题不是“缺少更多功能”，而是**代码完成、隔离通过、真实可用、对外承诺之间的差距还没有收口**。下一阶段应先减少这四种状态的偏差，再增加新功能。

## 主要风险与处理原则

1. **真实验收积压**：优先关闭 B-0001/B-0002，再安排 B-0004–B-0008。每次只在隔离工作区或作者明确的测试文章上操作。
2. **测试与时间耦合**：时间相关测试必须使用相对时间或固定时钟，不能写早于运行时创建时间的硬编码日期。本轮已修正导入进度测试。
3. **视觉证据不足**：原型、浏览器窄视口和静态契约只作设计/结构证据，真实宿主截图和录屏才可关闭视觉槽位。
4. **功能入口过多**：每个入口都要回答“用户现在为什么看到、点击后改变什么、失败后怎么继续”；没有清晰主路径的入口应收纳或延后。
5. **AI 信任成本**：所有 AI 结果必须显示来源、动作、通道、时间和依据；关闭、额度不足和模型不可用时，主阅读链路仍完整。
6. **对外承诺超前**：README、头像、预览图、集市描述和 GitHub 首页只能使用能力矩阵的保守口径。

## 建议开发节奏

1. 先完成 T-3274，恢复全量绿灯并固定证据格式。
2. 用一次桌面会话完成 T-3275、T-3278，失败项立即转成可复现 blocker。
3. 用一次 Android 会话完成 T-3276，真实移动问题单独排队，不与桌面截图混算。
4. 再做 T-3277、T-3285、T-3286 的外部环境验收；真实模型和订阅条件不足时保留 blocker。
5. 通过主链后处理 T-3279–T-3284 的视觉、无障碍、交互和性能问题。
6. 最后完成 T-3287–T-3291，对外材料和发布授权作为独立最后一步。

## 暂不应继续扩张的方向

- 不增加通用聊天窗、自动阅读、RSS 云同步或插件自带 LLM 密钥。
- 不把 AV 双向编辑、原文块级排版撤销、视觉图片理解写成已支持能力。
- 不为了截图制造成功数据、伪造真机证据或把浏览器模拟器结果记为 Android 通过。
- 不在真实验收前继续堆叠新的属性、入口和跨插件协议；先把现有链路做成可解释、可恢复、可发布。
