# 小驴拾遗 UI 标准（UI-STANDARD）

> 本文档是小驴拾遗**唯一 UI 事实源**，贯穿整个开发周期：任何新界面/新组件先查这里，标准缺失时先补标准再写代码。
> 2026-09-29 D-0016 重整：本文的视觉令牌与画布规范继续适用；候选/已收录、阅读动作和验收语义以 [PRODUCT-REPLAN.md](PRODUCT-REPLAN.md) 为准。S3 的筛选、载体打开和聚焦阅读协议见 §5.8。历史章节与当前实现不一致处先按 T-1708 校正，不能把原型外观当成操作已可用。
> 设计语言定稿：**简约 · 现代 · 前沿 · 科技**（D-0011）。可视化规范 = `design/prototype.html`（与本文档同步维护，类名词表一致）。
> 布局参考系：Apple Liquid Glass / HarmonyOS NEXT / Material 3 Expressive / Linear、Readwise、Raindrop 等现代工具。

## 1. 设计原则（裁决冲突时按序取用）

1. **内容即界面**：文章标题永远是视觉主体；装饰（玻璃、光晕、渐变）只允许出现在"容器级"，不与内容争夺注意力。
2. **一屏一主任务**：每个视图只有一个主操作（面板=开读，迁移器=开始回填，设置=即时生效）。
3. **平静原则**：不打卡不羞辱——空态/统计文案零评判（"今天没有待拾的"，而非"落后 N 篇"）。
4. **数据可见即真相**：UI 展示的状态必须来自文档属性（对账后）；不展示无来源的推算。
5. **主题自适应**：只用 b3 变量取主题色，禁止硬编码明暗色值；深浅主题都必须可读。

## 2. 设计令牌（Tokens）

### 2.1 颜色

| 令牌 | 值 | 用途 |
|---|---|---|
| `--glean-accent-a / -b` | `#ffc15e / #f97316` | 品牌琥珀渐变两端 |
| `--glean-grad` | `linear-gradient(135deg, a, b)` | 主按钮、激活胶囊、进度条、品牌 mark |
| `--glean-grad-soft` | 10% 透明度渐变 | rail 激活项、轻量高亮 |
| `--glean-st-inbox` | `#f59e0b` | 新剪藏（状态色，用于状态点/徽章/光环） |
| `--glean-st-later` | `#3b82f6` | 稍后读 |
| `--glean-st-reading` | `#8b5cf6` | 阅读中 |
| `--glean-st-done` | `#10b981` | 已读 |
| `--glean-st-arch` | `#94a3b8` | 归档 |
| 主题色 | 只准 `--b3-theme-*` / `--b3-border-color` | 背景/表面/文字/边框 |

**状态色语义锁死**：五态颜色不得挪作他用；状态点必须带同色光环（`box-shadow: 0 0 5px currentColor`）。
**中性灰面**用 `rgba(128,128,128,.12±)` 做浅垫（hover/轨道/徽章底），不引入新灰色变量。

### 2.2 圆角 / 阴影 / 动效

| 令牌 | 值 | 用途 |
|---|---|---|
| `--glean-radius` | 16px | 卡片/面板块（Bento 18px、浮条 18px、小钮 8-11px、胶囊 999px） |
| `--glean-shadow-card` | 双层软阴影 | 卡片 hover 浮起 |
| `--glean-shadow-float` | 更强投影 | 浮动批量条、对话框 |
| `--glean-shadow-accent` | 品牌橙投影 | 渐变主按钮/激活胶囊 |
| `--glean-ease-spring` | `cubic-bezier(.34,1.56,.64,1)` | 按压缩放（:active scale .9-.985）、开关滑块 |
| `--glean-ease-out` | `cubic-bezier(.22,.61,.36,1)` | hover 位移、宽度过渡、胶囊激活 |

动效预算：微交互 ≤250ms；禁止常驻循环动画；列表入场不做 stagger（性能+克制）。

### 2.3 字体与数字

- 字号阶梯：11 / 11.5 / 12 / 12.8(卡片标题) / 13 / 13.5(弹窗标题) / 15(面板品牌) / 23(统计数字)。
- 卡片标题 600 字重；统计大数字 800 + `font-variant-numeric: tabular-nums` + 渐变裁切文字
  （`background-clip: text`，深→品牌橙 130%）。
- 不引入外部字体；跟随思源主题字体栈。

## 3. 布局系统（三档画布）

| 画布 | 宽度 | 形态 | 标准布局 |
|---|---|---|---|
| **Dock 面板** | 320px（用户可调 240-420） | 窄列 | 品牌行 → 视图胶囊 → 搜索 → 队列胶囊 → 单列卡片流 → 浮动批量条 |
| **Tab 桌面** | ≥600px | 全宽 | 品牌行+搜索（中）+视图/工具（右）→ 左 rail（队列/站点/标签，216px）→ 主区（列表/网格/看板） |
| **对话框** | 560-760px | 弹窗 | 玻璃头（mark+标题+副题）→ 步进器/内容 → 右对齐操作区；高度 ≤620px 内滚 |

**响应式规则**（真实现按容器区分，不写死断点）：
- `.glean-tab-root` ≥600px 时：库列表升级为行式表格（drow：状态点/标题/站点/字数时长/徽章五列），统计 Bento 升 4 列+双列图。
- Dock 恒为单列；rail 仅存在于 tab 画布。
- 看板（五列状态机）仅桌面画布提供；列宽均分，卡可拖（拖=改状态，见 §5.6）。

## 4. 组件规范（唯一类名词表，前缀 `glean-`）

实现与原型共用同一套类名；新增组件先在两处同步定义。

### 4.1 导航
- **视图胶囊** `glean-views`：3px 垫+滑块式激活（激活=表面色+小投影），当前四视图为今日拾遗/库/统计/高亮。
- **队列胶囊** `glean-q`：横滚、激活=品牌渐变白字+accent 投影，计数徽章 `.glean-q__n`。
- **时间线筛选条** `glean-filters`：队列、站点、用户标签、来源管道、时间来源和载体按需组合；筛选是视图状态，不写文章属性。Dock 使用可横滚 chips，Tab 使用 rail 与内容区的同一组筛选，移动端使用底部筛选 sheet。
- **桌面视图段** `d-seg`：列表 ☰ / 网格 ▦ / 看板 ⇆。
- **rail** `d-rail > rail-item`：216px 侧栏，分组标题 `rail-title`（10px 全大写 0.6px 字距），激活=soft 渐变底+橙字。

### 4.2 内容卡
- **面板卡** `glean-card`：状态点+单行标题+meta 行（站点·时长·吃灰徽章）+悬浮操作（右下 24px 方钮，hover 显）。
- **桌面行** `drow`：五列网格，归档行 60% 透明度降级。
- **看板卡** `kcard`：两行截断标题+meta（徽章 `white-space: nowrap`），`cursor: grab`。
- **高亮卡** `glean-hl`：左 3px 渐变竖条+引文+来源行。
- **状态徽章** `st-badge.<status>`：13% 状态色底+状态色字；吃灰徽章 `glean-stale` 仅 inbox/later 且 ≥14 天显示。

### 4.3 操作
- **主按钮** `glean-btn--pri`：品牌渐变+accent 投影，每视图至多一个。
- **次按钮** `glean-btn` / 幽灵 `glean-btn--ghost`。
- **图标钮** `glean-icon-btn`：28px 圆角 9，active 缩放 0.9。
- **胶囊收录** `glean-cap-btn` / 卡内 `glean-card__capture`：候选专属动作。
- **开关** `glean-sw`：36×21，激活=渐变+弹簧滑块；**chips** `glean-nb`：笔记本多选，激活=橙描边。

### 4.4 数据展示
- **Bento** `glean-tile`：18px 圆角+右上径向 glow+渐变大数字+spark 迷你柱（近 4 根热色）。
- **分布条** `glean-bar-row`：名称 76px / 轨道 6px / 计数右对齐。
- **周柱图** `big-chart`：列高 100% 底对齐（百分比高度才生效——踩过的坑），今天列 100%。

### 4.5 反馈
- **空态** `glean-empty`：72px 渐变圆角 art + 标题 + 两行提示；文案过平静原则。
- **加载** `glean-panel__loading`：居中灰字，禁止 spinner 堆砌。
- **进度** `glean-progress`：6px 轨道+渐变条+发光；配 `glean-prog-meta` 双端说明。
- **浮动批量条** `glean-batchbar`：玻璃+rise 入场，左计数右操作，主操作用 `glean-bb--pri`。
- **消息**：一律走思源 `showMessage`（2500-5000ms），不用 alert/confirm。
- **阅读上下文条** `glean-reading-context`：打开文章时显示标题、载体、来源和当前状态；正文仍由思源文档承载，不在本阶段渲染第二份正文。

### 4.6 迁移器步进器
`glean-stepper`：三步球（扫描报告→分批回填→完成），done=绿底✓ / on=渐变球+投影；配 `glean-mstats` 三卡（绿/灰/橙分色）。

## 5. 场景标准

### 5.1 面板（Dock）
v1.0.4 当前默认今日拾遗，`ui-prefs.json` 会跨重启记住上次视图；首次无数据时的引导和默认落点须按 S2/S3 重整。队列胶囊只在库视图出现。待确认候选必须与已收录 `inbox` 区分，见 PRODUCT-REPLAN §“统一对象与状态定义”。

### 5.2 桌面 tab
rail 筛选与队列互斥联动（选队列=清站点/标签筛选）；筛选可叠加时必须在内容区显示已选条件和“一键清除”。批量条在桌面改为内容区底部行式操作。排序入口与 Dock 使用相同选项和默认顺序。

### 5.3 看板（五列状态机）
列=五态（顺序 inbox→later→reading→done→archived 固定）；卡拖入新列=批量调 `batchSetStatus`
（写文档属性，属性为真相，D-0012）；列头计数实时；归档列 60% 透明。只在 ≥900px 画布提供。

### 5.4 对话框
迁移器/设置遵循 §3 第三行；关闭=右上 ✕ + Esc；迁移器关闭不丢进度（续跑语义 T-1102）。

### 5.5 设置
即时生效（改即存，无"保存"按钮）；分组标题全大写小字；每行 hover 反馈；危险区（维护）放最后。

### 5.6 AI 元素预留（M3 起）
AI 产出（摘要/标签/关联理由）一律带 ✨ 前缀标识+可关闭；AI 动作按钮统一 `✨ 前缀`；语义功能未启用时
整个区块隐藏（不显示禁用态）。

### 5.7 今日拾遗（M4）
渐变左条大卡：✨ 拾遗·第 N 篇（tag）→ 大标题（可点开）→ AI 摘要 → meta（标签/吃灰天数）→
三按钮「改天 / 归档 / 开始阅读」，主按钮=开始阅读；开始阅读进入 `reading` 并打开文档，读完必须在读库中明确标记已读。
卡下平静脚注（"改天没有成本 · 明天见"）。
空态 = 🌱 + "今天没有待拾的 / 明天再见，不用有负担"。重浮是每日默认首屏视图。

候选卡必须同时展示来源 URL（若有）、证据、缺失项和载体动作：补链接、作为本地文档收录、排除误报。候选不计入五态队列、配额、重浮或统计。

### 5.8 S3 阅读动作、筛选与聚焦上下文

管理视图和阅读上下文共用同一篇文档属性。Dock、Tab 工作台、看板和移动端只改变布局，不改变动作含义：

| 动作 | 写入 | 打开目标 | 反馈要求 |
|---|---|---|---|
| 开始阅读 | 显式写 `reading`；写入失败不打开 | 按载体策略打开正文或来源 | 显示载体徽章与当前状态 |
| 打开正文 | 不改状态 | 全文/本地文档打开思源文档 | 可从正文回到同一篇上下文 |
| 打开原文 | 不改状态 | 仅在有有效来源 URL 时打开网页 | 明确“不会标记读完” |
| 标记读完 | 显式写 `done` | 保持当前页面；“下一篇”另属 T-1723 | 成功后显示已读状态；失败保留 `reading` |
| 稍后读 | 显式写 `later` | 不自动打开下一篇 | 操作可重复，结果幂等 |
| 归档/恢复 | 归档写 `archived`；恢复默认写 `later` | 不自动打开 | 归档保留已读历史；恢复后回到活动队列 |

“打开标题”是低风险打开动作，不等同于开始阅读；主按钮“开始阅读”才进入 `reading`。任何画布的批量操作都走同一属性服务，并按实际成功数反馈。

时间线筛选只消费对账后的索引投影：状态、站点、用户 `tags`、来源管道、时间来源、载体、标题/URL 搜索和优先级/评分等排序均不写属性。用户标签只读根块 IAL 的 `tags`；AI 标签显示在独立的 AI 区域，不混入用户标签筛选。默认排序为 `custom-clip-time` 降序，再以文档 ID 降序稳定收尾；用户切换排序不得改变状态或 `last-surfaced`。

载体动作遵循全文优先：`fulltext` 主动作是“打开正文”，有有效来源 URL 时可提供“打开原文”次级动作；`link` 在来源 URL 有效时以“打开原文”为主动作并提示没有本地正文；`local` 只显示“打开文档”且不出现网页按钮。全文和仅链接的来源 URL 缺失或无效时隐藏网页动作并显示缺失提示；标题或“打开文档”仍可进入思源说明页，方便补齐来源，不把该动作当作成功阅读。移动端用可见按钮或动作 sheet 提供等同动作，不能只依赖桌面 hover。

聚焦阅读的 S3 最小实现是低干扰的上下文条或动作 sheet：标题、载体、来源和当前状态始终可见，正文由思源原生编辑器承载，关闭、返回和打开原文不写 `done`。本阶段不保存阅读百分比、滚动断点或自动高亮，也不提供自动跳转下一篇；这些能力必须先按 T-1728 修订数据契约。正文解析不完整时保留已有快照，提供缺失提示和“重新剪藏”入口，重新剪藏必须是用户显式动作。

当前实现将 `glean-reading-context` 挂在思源公开编辑器容器的正文外层，随文档加载、切换和销毁同步挂载与卸载；上下文状态从文档属性实时读取。返回按钮只回到读库并定位同一篇，来源按钮只打开经过校验的网页；两者都不写入完成状态。移动端使用相同可见动作，事件挂载仍需作者真机核验。

### 5.9 快照（M5）
卡片操作钮 📷/⟐ 二态：无快照=📷 拍摄（上传 assets 并写属性），有快照=⟐ 直接打开资产；
面板卡与桌面行表共用同一动作语义，悬停文案随状态切换。

## 6. i18n 与文案

- 任何界面字符串必须走 i18n 键（`zh_CN.json`+`en_US.json` 双份，parity 测试守门），禁止模板里写死中文。
- 文案语气：平静、直白、克制；数字用 `${n}` 插值；不吃嘲讽/催促词。
- 空态三段式：标题（4-8 字）+提示（一句话）+（可选）入口按钮。

## 7. 实现守门（与 AGENTS.md 联动）

1. 类名前缀 `glean-`；样式只写 `src/index.scss`（组件 `<style>` 留空占位）；颜色只用 b3 变量+本标准令牌。
2. 新组件 = 先在 `design/prototype.html` 加帧截图过审（自审三轮）→ 再回 port 实现 → 双向同步类名词表。
3. `pnpm check` 的 svelte a11y 告警允许白名单三类（点击容器/静态交互），但键盘可达性尽量补。
4. 本文档与 `design/prototype.html` 的冲突以**先更新的那份**为准，发现即修两处。
