> 集市与 README 的视觉材料拍摄手册。全部真机操作（作者），按本清单拍即可一次拍全。
> 视觉规范以 docs/UI-STANDARD.md 为准；截图前确认思源主题为默认（亮色为主，可补一张暗色）。

## 一、README 头图 GIF（约 15-25 秒，剪藏 → 消化闭环全流程）

演示脚本（按顺序操作，每步停 1.5-2 秒）：

1. 浏览器里打开一篇长文 → 官方剪藏扩展剪入思源
2. 切到拾遗面板「新剪藏」队列 → 新文章出现在待收录区 → 点「收录」；只有在真实模型已配置且作者明确开启自动富化时，才展示 ✨ 摘要生成，否则拍摄主链不放 AI 成功画面
3. 点「开始阅读」→ 状态点变紫
4. 切到「今日拾遗」→ 展示 3 张重浮卡 → 点一张卡的「✓ 读了」；打卡桥未完成真实联调前不把外部打卡结果作为截图卖点
5. 切到「统计」→ Bento 数字与分布图
6. （可选）拖一张看板卡到「已读」列

录制：Windows 用 ShareX（GIF，320px 面板区域裁剪，15fps）或 OBS+ffmpeg；
输出 `docs/media/demo.gif`（≤8MB），README 顶部插入。
