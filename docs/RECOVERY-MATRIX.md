# 恢复路径矩阵

> T-3216，2026-10-04。本文记录失败后的用户可继续路径。代码检查确认入口存在；真实断网、权限、宿主主题和设备行为仍按 blocker 验收。

| 故障域 | 触发 | 当前保留内容 | 恢复动作 | 代码证据 |
|---|---|---|---|---|
| 网络 | 浏览器离线或写入失败 | 已有索引、筛选、选择和输入 | 显示离线提示，恢复在线后点重试；写入失败不伪造成功 | `DockPanel.svelte`、`msg.offlineRetry` |
| 内核 | 对账/属性端点失败 | 旧索引和当前视图 | 保留旧数据，显示失败，用户点重新对账 | `DockPanel.svelte` 的 `loadError` / `loadIndex` |
| 权限 | 建文档、属性写入或外部删除失败 | 逐条进度、失败条目和本地文章属性 | 统计真实失败数，保留条目；导入完成页重试失败项 | `import-service.ts`、`ImportDialog.svelte`、`InboxSection.svelte` |
| 正文 | 正文缺失、导出失败、块定位失败 | 文章标题、来源、选区复制结果和原文入口 | 显示正文待核/来源降级；支持检测正文、重新剪藏或仅复制 | `ReaderTab.svelte`、`ReadingContext.svelte`、`excerpt-service.ts` |
| AI | 模型未配置、超时、解析失败、额度耗尽 | 原文、五态、手填属性和当前 UI 草稿 | 静默跳过并写脱敏日志；显示关闭/额度/失败说明，支持再次手动触发 | `enrich-service.ts`、`ReaderTab.svelte` |
| 导入 | 坏文件、笔记本加载失败、单条失败、执行期重复 | 预览、目标笔记本、文件解析结果、进度和已建文档 ID | 笔记本可单独重载；完成页只重试 `failedUrls`，根据 `failedItems` 复用原文档；属性已成功时只同步索引 | `ImportDialog.svelte`、`import-service.ts` |

## 保留约束

- 失败不得清空已有索引或把部分结果呈现为完整成功。
- 批量操作只移除真实成功 ID 对应的选择，失败项和执行期间新增的选择继续保留。
- 已有索引时后台对账保留列表/看板/收集箱组件，失败不卸载已有 DOM；并发刷新串行合并并补跑请求，避免旧结果覆盖新结果。
- 云端删除失败不隐藏云条目；用户仍可删除重试或核对已有文章，迁入/删除不并发。
- 导入保留预览和目标配置；重试只消费失败 URL，执行期仍再次查重。
- 已建文档的恢复先回读确认存在且来源未被改写；已存在有效状态时不重写状态、完成时间、用户标签或正文。缺失/来源改变时保留失败，不自动另建文档。
- 失败 URL/文档 ID 仅在当前弹窗内存保留；关闭或重载后应核对目标笔记本中的半成品，当前不提供跨重载自动恢复。
- AI 失败不写摘要/AI 标签，不改 URL、状态、优先级、评分和用户标签。
- 正文失败不覆盖用户正文，不把来源缺失伪装成全文。

静态回归不能替代真实权限错误、内核断开、断网恢复、模型超时和移动端操作；这些结果继续回填 `docs/BLOCKERS.md`。
