# 工作台与正文往返的会话协议（T-3366 / D-0245）

本协议只约束当前插件会话的导航结果交付，不新增文章属性、内核端点或持久化字段。工作台、Dock、浮窗和原生正文可以同时存在，不能以 CSS 画布类型代替确切页签身份。

1. 返回读库调用公开 SDK `openTab({custom})`，只向其返回的确切 `tab.id` 交付文章 ID。事件 `glean:focus-clip` 只携带 `tabId`；文章 ID 保留在插件内存的一次性映射中，由 `consumeLibraryFocus(tabId)` 消费。其他工作台、没有页签 ID 的浮窗和 Dock 均不能消费该请求。
2. 新的返回请求使旧请求失效；异步打开逆序完成时只有最新请求可定位。宿主创建成功但组件稍后挂载时保留一次性请求；目标关闭时清理，插件卸载时清空并使在途结果失效。当前打开失败显示既有失败提示，旧请求失败或卸载后的失败不干扰现页面。
3. 目标工作台切到读库，目标文章仍在当前筛选结果中时保留队列、筛选、排序和布局，并滚动高亮该行。若当前是窄布局且预览面板实际遮住列表、目标无法显出，只收起该预览以显示目标；宽布局的并排预览继续保留；直接进入预览的导航请求也保持预览。收起只改变当前会话，不改写已保存的预览偏好。被筛掉时才清除过滤条件并切到文章当前状态队列。文章不存在时终止定位，不制造文章或改写事实。定位等待对账/渲染，较新请求、切换视图或销毁后不滚动旧节点。
4. SDK 选择或新建目标页签；本轮不承诺回到最初打开正文的那个实例。目标已存在时沿用其会话状态；新建沿用现有初始化流程，返回请求优先于上次页面与默认保存视图，预览开关等其他偏好按既有流程恢复。隐藏的其他实例保留自己的筛选和滚动位置。返回定位滚动到确切文章，不承诺像素级恢复原滚动偏移。
5. 关闭/重建工作台、重载插件、重启宿主和跨设备后，没有新增筛选/滚动快照。现有 `ui-prefs.json` 的上次页面和显式保存视图继续按既有契约恢复；最近阅读仍只在当前插件会话内，不能扩写为跨重载恢复能力。

正文与预览生命周期（D-0246）：正文失败后的异步回焦必须核对失败前后焦点归属，用户主动移焦时不抢焦点；销毁后不回焦。预览慢写成功应广播真实数据变化，但关闭或切文后不展示旧提示、不刷新或推进旧预览；窄布局因返回读库而收起预览时同样退出原预览会话。不取消或重发已在途的属性写入。

验证分层：源码抽取 VM 覆盖多实例、逆序、失败、关闭/卸载和焦点竞争；隔离宿主用合成文章验证公开 SDK 返回身份与实际界面。它们不关闭 B-0002、GitHub #16 原场景或 24 项真实宿主视觉矩阵。原始实例返回、跨重建恢复和移动/读屏行为需单独立项与实证。
