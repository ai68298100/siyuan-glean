# 更新日志（CHANGELOG）

## v1.3.1（2026-10-09）

### 优化

- **大库刷新性能**：读库数据库绑定刷新使用 `Set` 做已有文档查重，避免大库场景下逐篇扫描列表；看板列在一次筛选排序后单遍按状态分桶，减少重复计算。

### 发布边界

- 类型/Svelte 检查、全量测试 1226/1226、生产构建、性能基线、发布产物和任务账本检查通过；真实宿主首屏、滚动、内存与低端设备收益仍需按 B-0002/B-0005 验收。

## v1.3.0（2026-10-09）

### 新增

- **设置页分类导航**：11 个平铺分组归并为工作区、每日拾遗、阅读、AI 增强、AI 通道、集成、数据与恢复、维护 8 个大类，"左侧导航 + 右侧内容"版式，每类配职责说明；对话框加宽至 720×640，窄容器/移动端自动降级为顶部横向标签。
- **读库笔记本筛选**：设置页选择笔记本支持搜索、已选计数与一键清空，多笔记本场景不再滚动寻找。
- **AI 标签规范化入口**：设置页按需扫描相似 AI 标签，逐组选择保留名称后合并；只改 AI 标签字段。

### 优化

- **保存视图跨画布保护**：保存视图改为条目级精确写回，一个画布新建/删除/设默认不再被另一画布的旧快照覆盖或复活；重名给出提示；工作台偏好读取失败时暂停自动保存。
- **导入防御加固**：导入解析对畸形导出文件的防御（超大字段截断、畸形时间戳拒绝、CSV 行上限）；损坏的导入进度文件可在界面"重置导入状态"（此前需手动删数据文件）；进度明细不再因上万条目卡顿；导入文件 32 MiB 上限。
- **分类导航键盘与触控**：方向键/Home/End 切换分类；44px 触控命中区在宽视口窄面板下同样生效；键盘焦点指示更完整。
- **收集箱**：查询失败提供重试入口；云端删除失败不再弹出互相覆盖的提示；已删条目即时从列表移除。

### 修复

- **阅读页签**：切文后"继续朗读"不再读出上一篇；阅读计时不再因瞬时读取失败被清零；外观按钮可正常开合；标题查询失败不再误报"加载失败"。
- **多编辑器定位**：分屏/多页签时"标记已读、收录、AI 摘要"等当前文档动作定位到正在看的文档；思源"设置→插件"齿轮入口恢复可用。
- **每日拾遗**：有"今日置顶"时不再坍缩为只剩置顶一篇；"读完并下一篇"正常推荐；滑动提示标签方向与实际动作对齐。
- **数据与并发**：派生索引并发写入互斥；设置保存多窗口冲突保护；存量迁移防双击并发回填；备份文件可重新选择、预览取消不再显示为错误。
- **筛选与显示**：筛选无结果时显示"没有符合当前筛选的文章"并提供清除筛选；候选行操作忙碌防护；本地文档来源列显示"本地笔记"；统计标签计数不因同篇重复标签虚增。
- **长操作健壮性**：大文档导出/快照上传改用 180 秒长超时；内核请求回退分支补超时与失败回调。
- **文案与显示**：修正约 30 处中英文表述（AI 调用量口径、导入确认措辞、快照写入位置等）；清理 30 个无引用文案键；多处原始英文错误改为本地化提示。

### 发布边界

- 静态门禁（类型/Svelte 0 错误 0 警告）、全量测试 1226/1226、隔离内核 S1 服务级 E2E 58/58、性能基线与发布产物检查通过；真实桌面、移动端、AI、外部集成和宿主视觉案例仍按能力矩阵与 BLOCKERS 待作者验收。

## v1.1.0（2026-09-30）

### 新增

- **可信收录**：候选凭来源证据入列，普通笔记与插件内部文档不再误报；跨笔记本 #剪藏 老文档纳入；URL 规范化查重，同来源冲突先核对再决定是否保留第二份
- **迁移器重做**：扫描→预览→确认→持久化任务→分批执行，支持暂停/恢复/失败重试，逐篇真实结果落盘
- **统一阅读时间线**：状态、站点、用户标签、来源、时间来源、载体与关键词筛选，排序稳定；Dock 侧栏、工作台、看板同一套动作
- **载体徽章与打开策略**：全文优先读思源正文，仅链接明确打开原文，本地文档不显示网页动作
- **内嵌阅读页签（实验，默认关）**：把思源编辑器嵌入插件页签——左侧正文（只读预览/编辑切换），右侧伴生栏集成状态动作、优先级评分、正文诊断、原文、快照
- **摘录与 AI 伴读（页签伴生栏）**：选中文本一键摘录为引述块/制卡/复制；总结全文、翻译选区、相关旧文以"动作+结果卡"呈现，可复制，总结可显式保存为 AI 摘要；AI 额度与富化共享
- **读完并下一篇**：显式动作，完成写入成功才切下一篇，不自动前进
- **排版优化**：长链接显示缩短、普通段落空行整理、可选推广/图片清理、乱码诊断和默认关闭的 AI 结构排版；原文对照确认后保存独立阅读整理稿。原文/属性不改，原文变更阻止旧预览保存，建稿后失败重试复用文档 ID；真实宿主与模型仍待 B-0002/B-0004
- **命令面板阅读动作**：标记已读/打开下一篇/稍后读/归档/打开原文/摘录选区/帮助（快捷键可在思源设置自定义）
- **完成时间**：显式标记已读写入完成时间，归档保留"读过"事实；"本周完成"与周报只认可信完成时间，不再用文档更新时间凑数
- **今日拾遗**：卡片注明"为什么出现"（吃灰天数/优先级/来源/近期未读主题）；改天幂等
- **超龄归档**：先展开候选清单逐篇勾选，确认后只归档勾选篇目
- **✨AI 标签独立筛选**：与用户标签分面分开并带来源标记；关键词搜索仍可同时命中
- **首启引导扫描预览**：只读展示已收录/待确认候选/缺来源计数，说明普通笔记不入库
- 数据主权验收用例进入自动化（16 项隔离内核断言）

- **全库摘录墙**：搜索、站点与两类标签分面、分页多选、原块回跳和校验后复制/CSV/Markdown 导出；内部导出稿不进入读库。
- **阅读回顾**：周/月/年、年度可信完成热力图、未知日期说明、独立候选快照及报告预览；报告失败恢复复用文档 ID。
- **对外桥接 v1**：属性投影读取、默认关闭的五态写入、注册冲突保护和卸载失效。

### 改进

- **首启引导更专注**：不再询问 AI 自动化（保持默认仅手动），能力卡提示可稍后在设置开启；有待确认候选时一键直达工作台逐篇确认；导入器入口降级为文字链接
- **设置页瘦身**：AI 设置拆为「常用」与「通道 · 进阶」两段；"每批写入条数"移到迁移器执行现场
- **队列术语更清晰**："新剪藏"队列更名为"待分拣"，与"待确认候选"区分
- **管理密度收敛**：工作台行表与看板卡不再内联优先级/评分控件（卡片视图与阅读页签伴生栏仍可设置）；Dock 窄栏搜索默认折叠为图标；候选横幅在所有队列视图常驻；阅读条次级按钮收为图标
- **今日拾遗回执**：点"开始阅读"后当天显示"今天已开始"清单，一键继续阅读并顺路标记已读

### 修复

- AI 总结/翻译与富化/排版统一队列内检查额度；模型调用成功但解析/保存失败仍计调用消耗；相关旧文开关与建议读库范围守门。

- 选了读库笔记本却查不出候选（SQL 条件错误）
- 单篇/批量/看板改状态看似成功实则被写入保护拦截；现按真实成功数反馈
- 开启自动富化后队列互相等待、富化无法完成
- 迁移任务暂停被误标完成、进度丢失；现可暂停恢复与失败重试
- 迁移器与导入器绕过统一属性服务导致的属性/索引不一致
- Pocket CSV 行短于表头时解析崩溃
- 设置页打卡开关不生效（保存遗漏该字段）

## v1.0.0（2026-09-29 · 首个公开版本）

### 新功能

- **读库管理**：剪藏文章五态状态机（新剪藏/稍后读/阅读中/已读/归档），状态写入文档属性，卸载插件数据不丢
- **Dock 读库面板**：库/今日拾遗/统计/高亮 四视图；五队列 + 站点/标签筛选 + 排序 + 搜索 + 批量操作
- **存量迁移器**：dry-run 报告先行，分批回填（≤50/批）可暂停续跑，永不覆盖手填字段
- **收录入口三件套**：面板一键收录（含批量）/ 编辑器右键"加入读库" / 命令面板
- **今日拾遗（抗吃灰）**：每日确定性重浮 N 篇（吃灰权重 + 优先级 + 多样性降权），读了/改天/归档零成本
- **队列配额与超龄归档**：收件箱超上限温和提醒，超龄文章一键批量归档
- **AI 富化**（走思源自带 AI，可选免费模型）：一句话摘要 + AI 标签；三态触发（关闭/仅手动/收录时自动）+ 每日次数上限 + 今日用量显示；失败静默降级不阻断收录
- **语义查重与相关旧文**：嵌入模型检索（不耗 LLM token），重复收藏提醒、阅读时推荐库内相关文章
- **预置 AI 动作**：拾遗·总结 / 要点 / 反方观点（可改 prompt）
- **智能体工具**：list_unread / archive_stale / weekly_digest，思源 AI 可直接调用
- **读库数据库（看板）**：一键挂载，看板列即状态机，拖卡改状态
- **阅读统计**：Bento 概览 + 近 7 天收录趋势 + 站点/标签分布 + 一键生成 Markdown 周报
- **高亮聚合**：当前文档引述块自动聚合
- **桌面画布**：筛选侧栏 + 行式表格 + 五列看板（拖卡改状态）+ 全宽统计

### 数据主权

- 一切文章状态写入文档属性（`custom-clip-*`）；插件卸载后数据原样保留
- AI 摘要/标签与用户标签完全隔离，永不覆盖手填字段
