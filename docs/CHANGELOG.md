# 更新日志（CHANGELOG）

## 未发布（v1.3.7 之后）

### 新增与体验增强

- **读库分面筛选器单项 Escape 清空与键盘交互闭环（T-3403）**：读库分面筛选器（`LibraryFilters`）的站点、标签以及高级筛选浮层内的作者、AI 标签、来源、时间源、载体类型、预计时长共 8 项下拉选择框全部接入 Escape 快捷键；在下拉框获焦时按 Escape 立即将该项重置为默认值并阻断事件冒泡。
- **阅读伴读 AI 结果卡片可关闭与问答输入 Escape 清空（T-3402）**：阅读页签（`ReaderTab`）AI 伴读结果（`aiResult`，总结/翻译）与文章提问问答（`questionResult`）卡片内提供明确的关闭按钮（`action.close`）；问答输入框监听 Escape 快捷清空草稿；主键盘事件处理 `Escape` 时同步关闭常驻的 AI 结果卡片。
- **阅读器全键盘工作流对齐（T-3401）**：阅读页签（`ReaderTab`）单键快捷流增加 `a` 转稍后读（保留已累计阅读时长）、`o` 在新标签页打开外部原文；`a`/`o` 同样禁止长按重复；按 `Escape` 支持退出快捷键帮助浮层或关闭外观/更多工具弹层；快捷键帮助列表（`<dl>`）展示新键位并同步双语。
- **今日拾遗桌面端全键盘分拣流（T-3400）**：今日拾遗（`ResurfaceView`）每日重浮卡片支持桌面端纯键盘操作——`J`/`K` 移动卡片光标，`Enter`/`R` 开始阅读，`A` 改天，`E` 归档，`H` 换一篇（今日拾遗专属备用池替补）；顶部提供 `glean-kbdhint` 行内快捷键提示与读屏播报，卡片具有高亮光标描边与 `aria-current` 标记；按 `Escape` 支持多层退出（先关撤销/换文提示，再退光标）。
- **摘录墙行级键盘导航（T-3399）**：摘录墙当前页卡片支持键盘操作——`J`/`K` 移动光标、`X` 勾选、`Enter` 打开原文、`Escape` 退出光标（导出预览打开时优先关闭预览）；方向键仍保留列表原生滚动，翻页或切换筛选后光标自动失效。键盘规则复用读库的同一套仲裁层，输入法、修饰键与输入框内一律让出。
- **读库键盘流批量选择收尾键位（T-3398）**：读库键盘操作新增 `S` 选择已显示（需键盘光标）、`F` 仅保留当前筛选、`C` 清空选择；`F`/`C` 只要存在勾选即可触发，按 `Esc` 退出光标后仍能顺手收拢或清空批量集合，长按不会重复执行。行内快捷键提示条同步展示三条新键位，批量条既有的读屏范围摘要继续播报选择变化。
- **情境选文标签别名贯通与 Escape 快捷清空（T-3397）**：情境选文面板（`ContextSelectionPanel`）接入 `tagAliases` 偏好观察与实时更新，标签下拉选项与理由卡片（`reasonText`）统一投影用户友好的标签别名；控件区域接入 Escape 快捷键清空已选主题标签，保持会话纯投影与数据主权不变。
- **今日拾遗撤销与换篇提示 Escape 快捷关闭与焦点闭环（T-3396）**：今日拾遗视图（`ResurfaceView`）挂载 `<svelte:window>` Escape 快捷退出，在非忙碌时按 Escape 即可快捷关闭操作撤销条（`undoNotice`，将焦点安全回退至可用卡片标题）并清空换文提示（`replacementNotice`）。
- **统计回顾预览与日期过滤 Escape 退出交互（T-3395）**：统计视图（`StatsView`）回顾预览区接入 `<svelte:window>` Escape 快捷退出，在非忙碌时按 Escape 即可放弃并退出预览草稿；在热力图或近期趋势表格中按日期联动过滤已完成文章列表时，按 Escape 快捷清除单日过滤回到完整完成文章列表。
- **摘录墙全库制卡贯通与导出预览 Escape 退出交互（T-3394）**：解除原先在全库摘录墙浏览时制卡按钮被隐藏的限制，浏览全库高亮时也可一键为任意金句或要点制作思源 riff 闪卡；导出预览区接入 `<svelte:window>` Escape 快捷退出，并在搜索框支持按 Escape 一键清空搜索词与筛选。
- **智能聚合视图与动态规则过滤器（T-3393）**：保存视图契约扩展纳入 `readingTimeTier`（预计时长分档短/中/长篇）与 `favoriteOnly`（星标收藏）；新增 `SMART_VIEW_PRESETS` 动态规则预设（短文速读、深度长文、星标收藏、最久待办）与 `instantiateSmartViewPreset` 纯函数，支持去重命名与 20 个视图容量安全约束；Dock 工作台保存视图栏增设“智能预设”一键创建选择器，创建后即刻切换并异步落盘；保存视图加载与应用支持完整恢复预计时长分档。
- **读库全键盘操作流（T-3392）**：列表行、候选行与看板卡片支持无鼠标分拣——`J`/`K`（或上下方向键）移动光标，`Enter` 查看，`O` 打开原文，`R` 开始阅读，`A` 转稍后读，`E` 归档，`X` 切换选择，`Esc` 退出光标；`glean-kbdhint` 行内提示条说明键位，`aria-current` 与读屏播报标记当前条目。键位仲裁会主动让出输入法组合、Ctrl/Meta/Alt、Shift 组合、文本输入框、按钮原生回车与已打开的弹层，长按不会重复执行写入类动作；移动端不注册。纯会话状态，不写文章属性、偏好或端点。

## v1.3.4（2026-10-14）

### 一句话汇总

在保持功能和视觉意图不变的前提下，统一全局设计令牌，并提升异步操作、索引写入和迁移恢复的可靠性。

### 新增

- **三层设计令牌与审计**：增加原始值、语义值、组件值三层令牌，覆盖色彩、4px 间距、字体、圆角、阴影、层级和动效；新增 `pnpm tokens:audit` 与 [`docs/UI-STANDARD.md`](UI-STANDARD.md)。
- **迁移任务恢复保护**：检查点保存任务 ID、阶段、确切文档 ID 和游标；失败行可根据当前文档事实重新确认和重试。

### 优化

- **样式一致性**：间距令牌覆盖率 36.7%→96.7%，字号/行高/字重/字距 31.6%→99.8%，圆角、阴影、层级和动效达到 100%；颜色字面量由 32 处/27 种降至 24 处/20 种，令牌声明由 231 个降至 210 个。
- **异步操作反馈**：内核请求、迁移、批量动作和 AI 标签整理统一忙碌锁、超时、竞态保护、失败分类、焦点定位和可重试入口。
- **恢复与刷新**：增量迁移按批次更新界面；AV 刷新容忍短暂索引延迟；今日拾遗、设置和筛选的空态、错误态与文案保持一致。

### 修复

- **索引一致性**：索引读取/保存异常不再静默成功；事实源回读失败会提示刷新或重建，完整对账/重建可解除损坏保护。
- **写入边界**：修复检查点压缩、任务身份竞态、表单校验与无效入口禁用，避免重复提交、旧响应覆盖新结果和重复 AV 绑定。

### 发布边界

- 自动门禁、生产构建、性能基线、视觉登记和独立内核验证按候选文档执行；真实思源宿主视觉、读屏、移动端和外部能力仍待 B-0002/B-0005，不能写作全平台已验证。本次只发布 GitHub，不提交集市 PR。
