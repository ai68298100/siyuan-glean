# 路线图（ROADMAP）

> **当前路线（2026-09-29，D-0016）**：以 [PRODUCT-REPLAN.md](PRODUCT-REPLAN.md) 的用户步骤、缺陷证据和验收口径为准。旧 M0–M5 章节是代码实现的历史规划，不能作为“已验收”或后续版本承诺。数据主权和契约先行规则不变；自定义 AI 通道以 D-0015 的修订为准。

## 当前修复与验收顺序

| 阶段 | 用户得到的结果 | 交付门槛 |
|---|---|---|
| S0 事实对齐 | 知道插件到底解决什么问题、现有哪些能力和缺陷 | 产品主线、任务、决策与待验收清单落盘 |
| S1 主链救火 | 能发现、迁移、收录、改状态，操作结果可信 | 隔离内核真实流程通过；状态/迁移/AI 自动队列的 P0 关闭 |
| S2 可信收录 | 普通笔记不会误入；每篇文章的来源和内容类型清楚 | 候选资格、跨笔记本标签、URL-only、元数据和索引对账通过 |
| S3 阅读动作 | 在任意画布可开始读、完成、归档和找回 | 属性、索引、界面一致，评分/优先级/筛选可用 |
| S4 拾遗与回顾 | 今日推荐、超龄处理、周报反映真实阅读 | 时间与完成历史可信、批量操作可复核 |
| S5 可选能力 | AI、数据库、收集箱、导入、快照、制卡、协同逐项可用 | 每项独立验收；未验证能力不承诺双向或自动效果 |
| S6 发布门禁 | 真实文章完整走通，卸载后数据仍在 | T-1108 E2E、桌面真机验收、移动/浏览器兼容声明核对、文档与 RELEASE 门禁通过 |

每项分别记录**实现完成 / 隔离验证 / 真机验收**；当前 v1.0.4 已发布的事实不因此改变。新版本的 tag、Release 和集市仍按 D-0005 逐次请示。
