# 作者真机验收手册（ACCEPTANCE）

> 用途：BLOCKERS 里需要真人/真机/真实服务的验收项，按本手册逐项操作并勾选。三态记账原则：**代码完成 / 隔离验证通过 / 真机验收通过**是三件事，本手册只覆盖最后一态；AI 不驱动真机（B-0010 红线不变）。
> 问题反馈格式：`验收项编号 / 操作步骤 / 预期 / 实际（附截图）`。确认的问题按"当日修复 → 补丁版"流程处理。
> 全部通过后进入 S6 发布评审（版本号、CHANGELOG、发版材料另议，见 §9 发布预检）。

## 0. 环境准备（二选一）

- **A. 真机装包**：从 GitHub Latest Release 下载 `package.zip` 安装；**覆盖安装后必须重启思源**（运行中覆盖，旧代码仍在内存）。
- **B. 隔离联调环境**：`node scripts/e2e/launch-e2e.mjs`（回环 6833，自带 GleanE2E 演示数据），用桌面客户端打开该临时工作区走查；不影响常驻工作区。
- 通用前提：插件设置里选择**读库笔记本**；AI 相关验收需先配置模型（思源原生 AI，或设置→AI→自定义通道+密钥库）。

## 1. B-0001 官方剪藏扩展实剪（约 5 分钟）

1. 浏览器装官方 SiYuan 剪藏扩展，指向你的思源。
2. 实剪 3 个站：一篇长全文、一个仅摘要/仅链接的页面、一个需登录的页面。
3. 回思源：打开拾遗面板，在候选横幅/「待分拣」队列核对候选。

**预期**：三篇都以候选出现（或已带官方属性直接入列）；候选卡显示证据（URL 属性/模板链接）；收录后 URL/站点/全文或仅链接载体判定正确；普通笔记不出现在候选里。

## 3. B-0004 真实 AI（约 15 分钟，需配置模型）

1. 富化：卡上 ✨ 手动富化 → 摘要/AI 标签写入（AI 标签独立于用户标签）。
2. 语义查重：富化一篇与库内相似文章 → 相似提示。
3. 相关旧文：阅读页签伴读段 🔗 → 列表可点击页签内跳转（嵌入未启用时按钮/提示降级）。
4. 伴读 ✨总结全文：结果卡显示「AI·通道·动作」标记；复制可用；"保存为 AI 摘要"后属性可见。
5. 伴读 文A 翻译选区：先选中文本，译文入结果卡。
6. 预置 AI 动作三件（总结/要点/反方观点）与智能体工具三件（list_unread/archive_stale/weekly_digest）。
7. 额度与开关：每日上限设 1 → 第 2 次提示额度；富化模式设 off → 富化/伴读段显示提示而非调用，收录主流程不受影响。

## 4. B-0005 导入器（约 10 分钟）

用真实 Pocket HTML/CSV、Omnivore JSON、wallabag JSON 导出文件各跑一遍：解析条数、文件内去重、库内 URL 去重、历史收藏时间（Pocket CSV 的 time_read 应落到完成时间）、已读/归档状态映射；仅链接条目在阅读里明确标识并可打开原文。

## 5. B-0006 全页快照

卡上 📷 生成 → ⟐ 打开资产。确认是"思源文档的单文件 HTML 快照"，断网也能看正文；快照不覆盖原文。

## 6. B-0007 思源收集箱（需订阅）

面板收集箱折叠区可见条目 → 迁入（全文与时间带过来）→ 忽略（云端删除）；断网/失败时不阻塞，可重试；同 URL 不重复迁入。

## 7. B-0008 小驴打卡桥

装小驴打卡 → 拾遗设置"协同·打卡"开启并选目标 → 读完一篇文章（重浮 ✓ 读了 / 标记已读 / 命令）→ 打卡端出现记录；同日重复读完不重复记录；打卡插件缺席时拾遗主流程不受影响。

## 8. 数据主权抽查（对应 T-1108，已脚本化）

任选一篇 → 右键"属性"看 `custom-clip-*`；**禁用/卸载拾遗插件** → 属性仍在（内核数据）；重装后"重建索引"与属性一致。隔离内核等价用例已进 `scripts/e2e/s1-flow.mjs` 最后一项断言。
