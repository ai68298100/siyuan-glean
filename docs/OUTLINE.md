# 阅读大纲

阅读页签的大纲只读取当前文档真实标题块，保留h1–h6实际级别，不补造层级。标题按正文顺序显示，包含引述、列表等容器中的标题。SQL的sort/id只用于分页取全；多个标题sort相同，不能用随机ID决定章节顺序。原生getChildBlocks决定顺序，标题不重复遍历逻辑子块。

点击标题先在当前Protyle宿主内寻找对应节点并滚动。节点尚未渲染时打开原块；切文/卸载使旧遍历失效，已发请求返回后不继续请求旧文容器。文章更新会刷新大纲。

缺项、重复、源变化、循环、请求失败或遍历预算超限会显示失败和“重试大纲”，不展示成功的部分结果；正文和属性不变。根/引述内标题顺序已在隔离3.8.6中验证，真实Protyle滚动和长文性能仍需B-0002验收。

阅读工具条提供“专注阅读/展开伴生栏”，重载后恢复展示偏好；工具条仍可切换阅读/编辑。点击“键盘阅读”（可用Tab选中按钮后Enter）聚焦正文，再用j/k滚动、e编辑、m标记已读、x摘录正文完整选区、?帮助。输入、编辑、IME、菜单和弹窗内不接管；长按只允许滚动重复。打开/隐藏栏/切换模式不自动写文章状态。
