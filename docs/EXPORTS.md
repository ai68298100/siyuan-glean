# 导出与诊断

设置页的“导出读库 CSV”会先执行一次完整对账，再读取有效、非 internal 文章的白名单属性。CSV 包含文档定位元数据和 `custom-clip-*` 的公开投影；用户标签与 AI 标签分列，未知属性为空，单元格会做 RFC 引号转义和公式前缀保护。正文、任意原始 IAL、密钥和模型地址不进入文件。

“导出匿名诊断”只包含插件/协议版本、对账时间与数量、功能开关、前端类型和匿名阶段错误。对账失败时不会用旧索引伪装成功，诊断明确标记 `fresh:false` 并给出失败阶段。

CSV 对账失败会保留错误并提供重试；诊断可以下载失败阶段信息，便于反馈问题。导出文件由浏览器下载到用户选择的默认下载位置，不新增文章属性或 saveData 文件。
