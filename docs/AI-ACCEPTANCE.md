# AI 真实模型验收矩阵与失败样本库

> T-3211，2026-10-04。本文只定义真实模型验收方法和证据格式。`pnpm test`、隔离内核和静态检查只能证明调用边界与降级代码存在，不能替代真实模型质量验收。当前真实模型验收仍归 B-0004。

## 1. 验收原则

- 先用可控短文和测试笔记本，确认动作、属性和失败恢复，再用长文验证截断与耗时。
- 每个成功样本都要同时检查结果质量、通道标记、用量计数和 `custom-clip-url/status/priority/rating` 未被改写。
- 每个失败样本都要确认原文、五态、用户标签和手填属性保留，界面给出下一步；模型失败不能阻断收录和阅读。
- 语义查重与相关旧文依赖嵌入开关，嵌入未启用时应隐藏或说明降级，不能把空结果说成“没有相似文章”。
- 记录模型名、前端和结果，不记录 API key、密钥名对应的值、完整文章正文或完整私密提示词。

## 2. 真实模型前置条件

| 项目 | 官方通道 | 拾遗专用通道 |
|---|---|---|
| 宿主 | 思源桌面或可用的思源 AI 环境 | 思源桌面；浏览器挂载受 CORS 限制 |
| 配置 | 思源设置 → AI → AI 编辑器模型 | 设置 → AI → 自定义通道；地址、模型和密钥库名称均有效 |
| 文章 | 测试笔记本内至少 3 篇有正文文章：相似、无关、长文 | 同左 |
| 嵌入 | 查重/相关旧文额外需要嵌入已启用且有索引 | 同左 |
| 数据保护 | 测试前记下 URL、status、priority、rating、用户 tags | 同左 |
| 证据 | 截图或录屏、操作时间、模型和失败日志阶段 | 同左 |

建议使用三个固定样本：

- `AI-A`：标题“CUDA 极简心智模型”，正文描述 CUDA 的线程层级和内存模型。
- `AI-B`：标题“CUDA 线程模型实践”，正文与 `AI-A` 有明显主题重叠但措辞不同。
- `AI-C`：一篇无关的阅读方法文章，以及一篇超过 6000 字的长文。

## 3. 主流程矩阵

| 编号 | 操作 | 通过标准 | 必查数据边界 | 结果记录 |
|---|---|---|---|---|
| `AI-01` | 官方通道对 `AI-A` 执行手动富化 | 得到一句话摘要和 2–6 个 AI 标签；AI 标签与用户标签分区显示 | 只新增/更新摘要和 AI 标签；URL/status/priority/rating 不变；用量加 1 | 截图摘要、标签、通道标记与前后属性摘要 |
| `AI-02` | 对 `AI-B` 执行富化并开启嵌入查重 | 显示相似文章提示；关闭嵌入后显示降级说明或隐藏，不显示误导性的“无相似” | 查重不改变文章属性；结果排除当前文档 | 相似提示、嵌入状态和候选标题 |
| `AI-03` | 在阅读伴生栏对 `AI-A` 总结全文 | 结果卡显示动作、通道和生成时间；复制可用；只有点击保存后才写 AI 摘要 | 调用前不写摘要；保存不改五态和正文 | 结果卡、保存前后属性和用量 |
| `AI-04` | 选中 `AI-A` 一段文字并执行翻译 | 结果卡只对应选区；模型失败时保留原选区和复制路径 | 失败不写正文、不写摘要、不改变状态 | 选区、结果卡或失败提示 |
| `AI-05` | 在阅读伴生栏打开相关旧文 | 嵌入开启时列出可点击相关文并能在页签内切换；嵌入关闭时隐藏或明确降级 | 点击相关文不改变当前文档状态 | 相关文列表、跳转结果和嵌入状态 |
| `AI-06` | 启用预置动作并检查三项动作 | “拾遗 · 总结/要点/反方观点”各存在且可执行；已有同名用户动作不被覆盖 | 不新增文章属性，不覆盖用户修改过的 prompt | 动作列表和一项结果截图 |
| `AI-07` | 在智能体中调用 `list_unread`、`archive_stale`、`weekly_digest` | 返回真实数量和可追溯文章；部分归档失败时分别报告成功/失败；周报口径与面板一致 | 不用尝试数冒充成功数；失败项属性保持不变 | 工具调用结果、成功 ID 和失败 ID |
| `AI-08` | 自定义通道完成一次 `AI-A` 富化 | 桌面端使用密钥库成功调用 OpenAI 兼容接口；浏览器端明确 CORS 降级 | API key 不出现在插件 saveData、日志或界面；切回官方通道可用 | 通道设置、连接结果、脱敏日志 |
| `AI-09` | 每日上限设为 1，连续及并行执行富化、总结、翻译或排版 | 队列内只有一个模型调用获准；第二次提示额度已满；排队期间 off 后跳过调用 | 未调用或模型调用失败不增加成功用量；已返回但解析/保存失败仍计调用消耗，收录和阅读主流程继续 | 用量显示、第二次提示、网络/内核调用记录 |

## 4. 失败样本库

以下样本是每次真实模型验收必须覆盖的最小集合。样本中的“预期阶段”对应 `ai-log.json` 的 `stage`，日志只保留脱敏后的短错误信息。

| 编号 | 构造方式 | 预期结果 | 不得发生 |
|---|---|---|---|
| `AI-F01` | 官方通道未配置模型后执行富化 | `skipped=error`，记录 `llm`，界面提示失败/配置模型，之后仍可手动重试 | 不写摘要/AI 标签；不把失败显示为成功；不阻断收录 |
| `AI-F02` | 模型返回普通文本或非法 JSON | `skipped=parse`，记录 `parse`，原文和状态保留 | 不写半截摘要；成功模型调用已消耗额度，不因解析失败退回 |
| `AI-F03` | 模型返回超长摘要、重复标签或带 `#` 标签 | 解析层规范化为有限长度和去重标签，或按解析失败降级 | 不写无限长/重复标签；不混入用户标签 |
| `AI-F04` | 自定义通道缺地址、模型或密钥 | 连接测试分别指出缺失项；业务调用静默失败并可重试 | 不把密钥写入 `settings.json`、`ai-log.json` 或 DOM |
| `AI-F05` | 自定义通道返回非 2xx、超时或不符合 choices 形状 | 记录脱敏错误，保留阅读主流程；恢复服务后可再次调用 | 不重试成并发风暴；不伪造结果 |
| `AI-F06` | 浏览器挂载使用自定义通道 | 显示桌面端使用说明或降级；官方通道仍按宿主能力处理 | 不在浏览器中暴露密钥或假设 CORS 可用 |
| `AI-F07` | 嵌入未启用或语义端点失败 | 相关旧文/查重隐藏或显示明确降级，正文和阅读可继续 | 不把空数组解释为“确认无相似” |
| `AI-F08` | 每日额度已满 | 跳过模型调用并显示额度提示；下一自然日可恢复 | 不增加用量；不修改文章属性 |
| `AI-F09` | 保存 AI 摘要时属性写入失败 | 结果卡保留可复制文本并提示重试；不报告已保存 | 不覆盖用户手填属性；不丢失当前结果 |

## 5. 结果记录模板

复制下面模板到验收记录，单条样本单独填写：

```text
样本编号：AI-__ / AI-F__
日期与宿主：
前端：desktop / mobile / browser-*
通道：siyuan / custom（只写模型名，不写密钥）
前置状态：嵌入 enabled/disabled；enrichMode；dailyCap；usageToday
操作：
预期：
实际：
数据主权抽查：URL/status/priority/rating/tags 前后是否一致
用量变化：
日志阶段：
证据：截图/录屏文件名
结论：通过 / 失败 / 阻塞
问题编号：
```

通过 `AI-01`–`AI-09` 和 `AI-F01`–`AI-F09` 后，才能关闭 B-0004。若只完成静态测试、隔离内核或无模型调用，T-3211 保持进行中，不能写成真实模型已验收。
