# 剪藏排版优化

> T-3219 / D-0063，2026-10-04。代码、纯函数/服务回归和真实隔离内核验证已完成；真实宿主显示与真实模型效果待 B-0002/B-0004。

## 使用路径

1. 打开已收录文章，在原生编辑器阅读上下文或桌面阅读页签点击“排版优化”。无需开启实验阅读页签。
2. 弹窗自动生成完整基础预览，显示原文和整理稿的 Markdown 对照。此阶段不建文档、不写属性。
3. 核对清理候选。疑似推广、重复图片、无说明图片默认全部保留，只有勾选的内容才从整理稿移除。
4. 需要 AI 时，在设置开启“AI 排版”并保存，保持 AI 总模式为手动或自动；回到弹窗点击“AI 一键排版”。页面先显示当前通道及文章文本发送说明。当前请求不发送图片字节或外链图片，图片候选只依据重复目标、缺少说明等结构证据。
5. 核对标题层级与清理候选后点击“保存阅读整理稿”。整理稿在原文所在笔记本、同级目录生成，名称包含原文标题、“阅读整理”和唯一后缀。点击“打开整理稿”在思源中阅读；原文回链和有效网页来源都在稿首。

## 基础整理与 AI 边界

| 问题 | 首版处理 | 保留边界 |
|---|---|---|
| 过长的裸 URL、URL 文字链接、自链接 | 显示为站点短标签，链接目标保留 | 已有有意义的链接名称不改；有括号/复杂标记等歧义时保留 |
| 普通段落间多余空行 | 收束到一个空行 | 复杂块及其邻接空白不调整 |
| 广告、关注、下载文案 | 根据短段落的明确前缀给出候选 | 不自动删除，也不认为所有讨论广告的正文都是广告 |
| 重复或无说明图片 | 根据独立图片段落的目标/alt 给出候选 | 不删除 assets；无说明不等于无意义；混合内容/复杂图片结构保留 |
| 替换字符和疑似异常编码 | 提示核对来源或重新剪藏 | 不猜测恢复，不由 AI 补写丢失信息 |
| 标题层级不清楚 | AI 建议将短单行普通段落提升为 H2/H3/H4 | 原句、段落顺序不变；模型不能提交替换正文 |
| 代码、公式、表格、引用、列表、HTML、块属性 | 排版规则不进一步修改导出正文中的复杂结构 | 原文的原生块 ID、IAL、引用关系均留在原文；整理稿是 Markdown 副本，不是原生无损复制 |

AI 使用已有官方/自定义通道、日志及每日额度，与富化共用串行队列。开关默认关，绝不因剪藏、打开或生成基础预览自动请求模型。当前通道只收到文章文本；不会读取、下载或发送图片字节，也不会把图片 URL 当作视觉输入。全文超过 24,000 个字符或 400 段时明确降级，完整基础预览仍在；不截断后伪称全文已整理。模型结果只允许 `headings` 和 `cleanup` 的段落编号计划，非法字段、未知编号、重复编号、保护块操作和多行标题均使整份计划拒绝。成功模型调用即计用量，包括非法计划；网络/模型调用失败沿用共享失败语义，不扣成功调用次数。日志不保存正文、提示词或原始模型回答。

“基础整理”可撤回本次 AI 结构计划；其基础候选的已有选择保留。重新读取原文会清空本次计划和选择，并生成新预览。

## 保存和恢复

| 情况 | 行为与下一步 |
|---|---|
| 原文正文、标题、路径、笔记本或来源 URL 变化 | 阻止保存旧预览，重新读取后核对 |
| 原文无法核对/不存在/失去有效读库状态 | 不建文档，恢复连接或返回读库核对 |
| 已创建文档，internal 标记或索引同步失败 | 显示新文档 ID，保留预览/选择；“重试完成整理稿”只复用该 ID 完成标记/索引 |
| 创建响应丢失或返回无效 ID | 当前预览禁止再建；先检查原笔记本的“阅读整理”文档，不能把异常当成服务器未写入 |
| 保存期间用宿主关闭弹窗 | 已授权的保存继续完成，完成或失败消息显示文档 ID；关闭后可在原笔记本核对 |
| 关闭后再打开 | 没有跨会话正文或恢复缓存；先核对已有整理稿，重新打开会生成新的独立预览 |

整理稿只通过 `clip-store` 写 `custom-clip-internal=true`，不复制原文状态/URL/评分/优先级/用户标签，不进入候选和阅读统计。原文不会被覆盖，也不删除资源文件。现有属性定义不变；新增持久化字段只有偏好 `settings.ai.formattingEnabled`。

本功能用已隔离实证的导出参数 `{id, yfm:false, addTitle:false, refMode:2}` 获取正文，避免把宿主自动附加的 YAML/文档标题作为文章正文，并保留思源块链目标。未修改用户全局导出设置。Markdown 导出本身会规范化原生嵌入、超级块等结构，因此需要保留这些复杂布局时请继续阅读原文；T-3220 研究块级编辑/撤销，不在首版宣称替代原生文档。
