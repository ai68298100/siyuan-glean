# 外部联调验收矩阵与失败样本库

> T-3212，2026-10-04。本文覆盖外部导入、思源收集箱、单文件 HTML 快照和小驴打卡桥。代码回归与隔离 spike 只能证明端点形状和降级路径，真实文件、订阅、assets 和双插件联调仍需作者按 B-0005–B-0008 操作。

## 1. 联调原则

- 每条链路都先做可用性检查，再执行写入；不可用时隐藏或跳过，不伪造成功。
- 迁入/导入/快照/打卡的成功数、跳过数、失败数和可重试项分开记录；云端删除或外部打卡失败不回滚已经明确成功的本地状态。
- URL 去重在预览和执行阶段都要发生；并发或预览过期不能制造第二篇文章。
- 外部系统的失败只影响对应外部动作，不能覆盖正文、用户标签、五态和手填属性，也不能阻断阅读主流程。
- 证据只记录脱敏 URL、文件格式、条数、状态和结果；不上传导出文件全文、账号信息或私人 token。

## 2. 前置条件

| 链路 | 必需环境 | 测试数据 | 真实状态 |
|---|---|---|---|
| 外部导入 | Pocket HTML/CSV、Omnivore JSON、wallabag JSON 的真实导出文件；目标读库笔记本 | 四种格式各一份，含未读、已读、归档、标签、重复 URL 和仅链接条目 | B-0005 |
| 思源收集箱 | 已登录思源、有效订阅/收集箱、目标读库笔记本 | 一条有正文、一条仅描述/链接、一条可重复迁入条目 | B-0007 |
| HTML 快照 | 可导出正文的文档、可写 assets、能打开资产的宿主 | 一篇含图片/链接的剪藏文档；一条空正文失败样本 | B-0006 |
| 打卡桥 | 启用小驴打卡插件并选择一个项目；协议 v5 | 一篇文章重复完成、换日完成、插件暂时不可用 | B-0008 |

## 3. 联调矩阵

| 编号 | 操作 | 通过标准 | 失败恢复与跳过 | 数据边界 |
|---|---|---|---|---|
| `INT-01` | 分别预览并执行 Pocket HTML/CSV、Omnivore JSON、wallabag JSON 导出 | 四种格式的条数、状态映射、历史时间、标签、仅链接载体均正确；库内和文件内 URL 去重 | 空文件/坏格式可重新选择；单条失败计入失败并继续；重复项可跳过 | 仅新建文档带入文件标签；不覆盖既有用户标签和已有属性 |
| `INT-02` | 打开收集箱、迁入全文条目、迁入仅链接条目、再次迁入同 URL；关闭并重载插件后继续处理 | 可用时显示条目；迁入后本地文档带正文/来源/时间；成功后云端删除；重复项保留云端供裁决；恢复点只沿同一云端 oId 和确切文档 ID 继续 | 未登录/无订阅隐藏入口；建文档或属性失败保留云条目；云端删除失败下次可重试；`capture-pending` 重载后可重试本地收录，`remove-pending` 只重试云端删除，`unknown` 不自动重建 | 云端删除不是本地成功条件；不因失败删云端，不创建重复文章；不能按标题、路径或最近文档猜测认领 |
| `INT-03` | 手动生成快照；另在开启 `snapshotOnCapture` 后收录一篇文章并检查自动路径；打开资产、修改原文后再打开快照 | 生成单文件 HTML，assets 路径写入快照属性，资产可打开且保留收录时内容；自动路径只生成一次且不阻断收录 | 导出为空或写 assets 失败可重试；失败不写空快照、不回滚已成功收录；属性已写入但索引保存失败时显示“索引待同步”并可重建 | 只写 `custom-clip-snapshot`；打开快照不改变五态、正文或用户属性；自动快照默认关闭 |
| `INT-04` | 打卡插件可用时记录读完、同日重复、换日再次记录 | 项目选择正确；首次记录成功；相同 `externalRef` 返回重复；跨日产生新引用 | 插件缺席、未就绪、无能力或写入失败只记录不可用/拒绝，主流程仍显示已读且可稍后重试 | 只在用户开启协同且读完成功后调用；不把打卡结果当作读库状态 |
| `AV-01` | 挂载读库 AV，刷新并读回已绑定文章行；在短暂空结果后再次刷新 | 只做属性→AV 的单向状态投影；已有数据库/绑定 ID 可找回；状态读回与文章属性一致；刷新不重复建库或重复绑定 | AV 不可用、绑定或刷新失败显示可重试错误；短暂索引延迟等待后再判定；不把空结果当作数据库不存在 | 当前仅承诺属性→AV 状态列；字数、时长、URL 等列尚未完成稳定映射；不承诺 AV 编辑反向写属性（D-0094/T-3247） |
| `CARD-01` | 选区摘录制卡，编辑草稿后明确确认；开启问句制卡再执行一次；重载后继续恢复 | 只在明确确认后创建卡片并登记确切卡块 ID；问句动作受 AI 开关/额度约束；恢复只处理同一检查点和卡块 | riff 不可用、登记失败或检查点读写失败保留可重试状态；插入结果未知时禁止自动重建；重载不得重复建卡 | 卡片宿主文档标记为 internal；不改文章五态和用户手填属性；真实 riff/宿主重载仍待 B-0002/B-0006 |

## 4. 失败样本库

| 编号 | 构造方式 | 预期结果 | 不得发生 |
|---|---|---|---|
| `INT-F01` | 导入空文件、坏 JSON、缺 URL 的行 | 预览显示空/无效项说明；用户可换文件或跳过 | 创建空文档、写伪造 URL、把坏行算成功 |
| `INT-F02` | 预览后先由另一流程创建同 URL 文档，再执行导入 | 执行期再次查重并跳过，进度继续 | 依赖过期预览创建重复文档 |
| `INT-F03` | 导入中单篇建文档返回空 ID、属性写失败或索引保存失败 | 该行计失败，后续行继续；完成页只重试失败行，已返回文档 ID 时复用；属性已成功时只修复索引 | 把失败行计入 imported；伪报全批成功；重试重复建文档或覆盖用户修改 |
| `INT-F04` | 收集箱不可用、详情读取失败或目标笔记本无效 | 隐藏/提示不可用；云条目保持原状，恢复后可重试 | 删除云端条目或写入不完整本地条目 |
| `INT-F05` | 收集箱本地迁入成功但云端删除返回错误；关闭并重载插件后点击专用删除重试；另开第二窗口同时迁入同一条目 | 本地成功与云端删除失败分开显示；保留云条目，提供专用删除重试和本地文章入口；重载后 `remove-pending` 仍指向同一确切文档 ID；并发窗口最多一个事务继续，另一窗口明确提示忙碌 | 为了清理界面强制删除、隐藏失败条目、重试时重新建文档或覆盖其他窗口的检查点 |
| `INT-F06` | 快照导出为空、资产写入非 2xx、打开资产失败，或属性已写入但索引保存失败 | 不写空路径；已有旧快照保留；索引失败只标记待同步并允许重建；提示重试 | 不覆盖正文、清空旧快照、把路径或索引状态写成成功 |
| `INT-F07` | 打卡插件缺席、协议错误、未 ready 或能力缺失 | 返回 `unavailable`/`rejected`；日志留痕；读库已读状态不回滚 | 抛裸异常、阻断“标记已读”、伪报已打卡 |
| `INT-F08` | 同一文档同一天连续触发读完 | 第二次使用相同 `externalRef`，宿主返回重复或幂等成功 | 写入两条相同日期记录或把重复当新完成 |
| `INT-F09` | 开启自动快照后收录失败、重复收录或快照资产写入失败 | 收录事实与快照结果分开报告；重复项不重复生成；快照失败项可单独重试 | 为了生成快照覆盖正文、把快照失败算作收录失败、无检查点时自动重建未知资产 |
| `AV-F01` | AV 查询短暂为空、已有绑定 ID 不可见、绑定或状态读回失败 | 有界重试后仍失败则显示错误并保留文章属性；不重复建库或绑定；用户可显式重试 | 把延迟空结果当成不存在、创建第二个数据库、把 AV 编辑结果写回属性 |
| `CARD-F01` | 插入结果未知、riff 登记失败、检查点损坏/读取失败或重载后卡块缺失 | 保留恢复检查点和可重试提示；未知结果禁止自动重建；缺失卡块要求用户重新确认 | 重复创建卡片、认领其他卡块、覆盖用户宿主文档或把登记失败显示为已制卡 |
