# 小驴拾遗 (Lv Glean)

> **把吃灰的收藏捡回来喂给自己。**
> *Glean your clippings before they gather dust.*

小驴拾遗是思源笔记的剪藏文章管理插件：把官方剪藏扩展、收集箱、各种导入方式存进思源、然后**再也没打开过**的文章，变成一个有生命周期、能被消化的阅读库。数据全部落在文档属性上，卸载插件一个字段都不丢。

[English](README.en-US.md)

## 为什么需要它

用思源官方剪藏扩展存文章很方便——但剪回来的文章**没有任何可查询属性**：来源 URL 和时间只是正文里的一行模板文本，思源检索、数据库、查询都"管不了"它。于是收藏越来越多，打开的越来越少。

小驴拾遗的地基是一套**剪藏属性规范**（`custom-clip-*` 文档属性）+ 一个**存量回填迁移器**：3 分钟把你已经吃灰的剪藏库整理成可管理、可检索、可统计的读库。

## 功能

### 🗂 库管理（M1）
- **状态分拣五态**：新剪藏 → 稍后读 → 阅读中 → 已读 → 归档，写在文档属性上，任何端点/工具都能读
- **Dock 读库面板**：五队列 + 站点/标题/标签筛选 + 按时间/字数/优先级排序 + 批量操作
- **存量迁移器**：先看 dry-run 报告再写入；分批回填（每批 ≤50）可中断续跑；幂等不覆盖手填字段
- **收录入口三件套**：面板"新剪藏"区一键收录 / 编辑器右键"加入读库" / 命令面板
- **数据主权**：一切状态都在你的文档上；插件只存一份可随时重建的轻索引

### 🤖 AI 富化（M3，走思源自带 AI，零额外付费）
- 收录时自动**一句话摘要 + AI 标签**（与用户标签完全隔离）
- **语义查重**：库里已有相似文章时提醒，拒绝重复收藏
- **关联旧文**：正在读的文章自动推荐库内相关内容
- 预置 **AI 动作**：总结 / 要点 / 反方观点，prompt 可改
- **智能体工具**：把读库暴露给思源 AI（列未读/归档陈文/每周摘要）

### 🔄 抗吃灰三件套（M4，本插件灵魂）
- **每日重浮**：每天从吃灰堆里挑 N 篇进"今日拾遗"，平静原则——不打卡、不羞辱、跳过无成本
- **队列配额**：新剪藏超量温和提醒
- **超龄归档**：90 天未读自动进"归档候选"，一键批量归档

### 📊 统计与承接（M2/M5）
- 已读/字数/标签/站点统计，一键生成 Markdown 周报
- 挂库向导：一键创建"读库数据库"，看板视图即状态机
- Pocket / Omnivore / wallabag 迁移导入（ roadmap ）

## 3 分钟整理你的剪藏库

1. 安装并启用小驴拾遗，打开设置，把你放剪藏的笔记本选为**读库笔记本**（可多选）
2. 打开读库面板 → 点右上角 **整理剪藏库**
3. 先看 **dry-run 报告**（不写入）→ 确认无误点 **开始回填**
4. 完成！来源 URL、入库时间、字数、阅读时长都写到了每篇文章的属性上

之后新剪藏的文章在面板"新剪藏"区一键收录，或右键"加入读库"。

## 兼容与边界

- 思源 **v3.8.5+**；桌面端/移动端/浏览器端
- AI 功能走**你已配置的**思源 AI 模型，本插件不内置任何 API key、不订阅、不上传数据
- 与渐进阅读类插件**不冲突**：拾遗做管理端，不做阅读调度；预留"推入渐进阅读"集成
- 卸载插件：文档属性原样保留，仅派生索引随插件删除

```bash
pnpm spike      # 隔离内核 M0 spike（绝不触碰真实工作区）
```
